# השתול.טק 🌱

משחק מסיבות לטלפונים: כולם עונים על אותה שאלה, חוץ מאחד. תצליחו לתפוס אותו?
3–12 שחקנים, כל אחד בטלפון שלו, בלי הרשמה ובלי אפליקציה. מספיק קישור.

## העלאה ל-Render בחינם (בערך 10 דקות)

### 1. מעלים את הקוד ל-GitHub
1. נכנסים ל-https://github.com ופותחים חשבון אם אין.
2. לוחצים **New repository**, נותנים שם (למשל `hashtul-tech`) ולוחצים **Create**.
3. בעמוד הריק לוחצים **uploading an existing file**.
4. גוררים לשם את **כל התוכן** של התיקייה הזו (כולל התיקייה `public`) ולוחצים **Commit changes**.

### 2. יוצרים שירות ב-Render
1. נכנסים ל-https://render.com ונרשמים עם חשבון ה-GitHub.
2. **New → Web Service**, ובוחרים את ה-repository שיצרתם.
3. ממלאים:
   - **Runtime:** Node
   - **Build Command:** `echo ok`
   - **Start Command:** `node server.js`
   - **Instance Type:** Free
4. לוחצים **Deploy**. אחרי דקה-שתיים מקבלים כתובת כמו `https://hashtul-tech.onrender.com`.

זהו. שולחים את הכתובת לחברים.

### 3. (לא חובה) שאלות חדשות מ-Claude
אם רוצים שהמשחק ימציא שאלות חדשות בכל סיבוב:
1. יוצרים מפתח API ב-https://console.anthropic.com. זה בתשלום לפי שימוש, אבל ערב משחק עולה סנטים.
2. ב-Render: **Environment → Add Environment Variable**
   - Key: `ANTHROPIC_API_KEY`
   - Value: המפתח שלכם
3. שומרים. בלובי יופיע למארח כפתור "✨ Claude ממציא שאלות".

בלי מפתח המשחק עובד מצוין עם המאגר המובנה (58 זוגות שאלות).

## דברים שכדאי לדעת על Render בחינם
- **השרת נרדם** אחרי 15 דקות בלי שימוש. הכניסה הראשונה אחרי זה לוקחת 30–60 שניות. כדאי לפתוח את האתר דקה לפני שמתחילים.
- כל עוד משחקים השרת ער.
- החדרים נשמרים בזיכרון, אז כשהשרת נרדם או מתעדכן, חדרים פתוחים נסגרים. זה לא משנה לערב משחק.

## נושאי שאלות
המארח בוחר בלובי:
- 🛠️ **צוות מחשוב** (ברירת מחדל): סוגי טכנאים, קריאות, משתמשים ומדפסות. 37 זוגות.
- 💻 **טק כללי**: מחשבים, אינטרנט, גיימינג ו-AI. 58 זוגות.
- 🎲 **הכל**: שני הנושאים מעורבבים.

## עריכת השאלות
כל השאלות בקובץ `questions.js`, ברשימות `it` (צוות מחשוב) ו-`tech` (טק כללי). כל שורה בנויה כך:
```js
['n', 'השאלה של כולם', 'השאלה של השתול', מינימום, מקסימום],
```
סוגים:
- `n` מספר (סליידר, חייבים מינימום ומקסימום)
- `r` דירוג 1–10
- `w` מילה
- `p` מי בחדר

עורכים את הקובץ ישירות ב-GitHub (אייקון העיפרון), ו-Render מעדכן לבד.

## הרצה על המחשב
```
node server.js
```
ואז פותחים http://localhost:3000. צריך Node 18 ומעלה, בלי `npm install` ובלי ספריות חיצוניות.

## איך זה בנוי
- `server.js` הוא שרת Node בלי תלויות. כל הלוגיקה של המשחק רצה בשרת, וכל שחקן מקבל רק את השאלה שלו, אז אי אפשר לרמות דרך הדפדפן.
- העדכונים בזמן אמת עוברים ב-Server-Sent Events, והפעולות נשלחות כ-POST.
- `public/index.html` הוא כל צד הלקוח: עיצוב, מסכים ורטט בטלפון.
- אם הטלפון מתנתק או מרעננים את הדף, חוזרים לאותו חדר עם אותו ניקוד.
